# Roo Code Project Rules — Smart Campus AI Management System

## Primary Constraints
1. Refer to `AGENTS.md` and `.agents/rules/project-ai-development.md` as primary guidelines.
2. Design language: Use Google Stitch and Untitled UI visual hierarchy.
3. Backend: FastAPI in `sci/backend/`, SQLAlchemy, SQLite/MySQL.
4. Frontend: React 18, TypeScript, Tailwind CSS, Vite in `sci/frontend/`.
5. Testing: Playwright MCP for browser-level validation, pytest for backend.
6. Safety: Never expose or hardcode API keys, secrets, or database credentials.
